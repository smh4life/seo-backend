# Git Commands - Step by Step

## ✅ Step 1 Complete: Git Initialized!

Now let's connect to your GitHub repository and push your code.

---

## Step 2: Connect to Your GitHub Repository

Run this command:

```bash
git remote add origin https://github.com/smh4life/seo-backend.git
```

**Tell me what it says!** (It should say nothing if it works, or show an error)

---

## Step 3: Check What's in the Repository (Optional but Safe)

This lets us see what's already there:

```bash
git fetch origin
```

**Tell me what it says!**

---

## Step 4: Create a v2 Branch (Keeps Old Code Safe)

```bash
git checkout -b v2
```

**Tell me what it says!**

---

## Step 5: Add All Your Files

```bash
git add .
```

**Tell me what it says!** (Should say nothing if successful)

---

## Step 6: Commit Your Code

```bash
git commit -m "MySEOGenerator v2 - Complete rewrite"
```

**Tell me what it says!**

---

## Step 7: Push to GitHub

```bash
git push -u origin v2
```

**This might ask for your GitHub username and password/token. Tell me what happens!**

---

## Run These One at a Time:

1. `git remote add origin https://github.com/smh4life/seo-backend.git`
2. `git fetch origin`
3. `git checkout -b v2`
4. `git add .`
5. `git commit -m "MySEOGenerator v2 - Complete rewrite"`
6. `git push -u origin v2`
